# Controle Financeiro (base)

App de controle financeiro pessoal: lançamentos, contas fixas, cartões e faturas, investimentos e avisos no celular.
Roda de graça na Vercel + Upstash Redis, com os dados só na sua conta.

**Como usar:** faça uma cópia (fork) deste repositório e abra-a com o Claude. Ele lê o `CLAUDE.md` e guia a montagem
passo a passo. Para atualizar depois, veja o `CHANGELOG.md`.
